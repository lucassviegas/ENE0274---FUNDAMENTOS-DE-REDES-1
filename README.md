# ENE0274 - Fundamentos de Redes

Repositório com as atividades da disciplina **ENE0274 - Fundamentos de Redes**, cursada na Universidade de Brasília (UnB) sob orientação do professor **Laerte Peotta de Melo, Dr.**

A disciplina cobre conceitos fundamentais de redes de computadores, incluindo dispositivos de rede, tecnologias de acesso (ADSL, HFC, FTTH, Wi-Fi), captura e análise de tráfego com Wireshark, DNS, protocolos de e-mail (SMTP) e criptografia aplicada a redes (AES, modos de operação).

## Atividades

| Arquivo | Tema |

| [Atividade_01.md](Atividade_01.md) | Captura e análise de dados ICMP (local e remoto) com Wireshark |

| [Atividade_03.md](Atividade_03.md) | Tecnologias de acesso à internet (ADSL, HFC, FTTH, Wi-Fi) |

| [Atividade_06.md](Atividade_06.md) | Criptografia simétrica e modos de operação (AES, ECB, CBC, CTR) |
